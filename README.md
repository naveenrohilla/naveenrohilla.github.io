# Naveen Rohilla — Personal Portfolio Website

A responsive, single-page professional portfolio built with HTML, CSS and JavaScript.

## Preview locally
1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.

## Publish using GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `naveenrohilla.github.io`.
2. Upload all files and folders from this project (keep the `assets` folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. After GitHub Pages finishes deploying, visit `https://naveenrohilla.github.io`.

Your existing profile repository `naveenrohilla` can remain as it is. The website should use the separate `naveenrohilla.github.io` repository for the clean profile-site URL.

## Before publishing
- Confirm that the phone number and email in the contact section should be public.
- The resume PDF is included in `assets/` and is downloadable from the page.
- The content is based on the supplied resume. Review dates and wording before publishing.
